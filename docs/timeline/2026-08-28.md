## 经验教训 → 代码与 SKILL 改进项

| # | 教训 | 已转化的改进 |

| 4 | daemon 子进程锁 `target\debug\aitrace.exe`，链接 os error 5 | 规则：先停 daemon 再构建（SKILL/CLAUDE.md） |
| 5 | MCP server 不随部署升级，易验收到旧代码 | 规则：serverInfo.version 核查 + 提醒人类重连 |
| 6 | PostToolUse 晚于文件落盘，enrichment 是竞态掷硬币（**用户重启验收抓到**） | 代码：HOOK_GRACE 250ms；测试：端到端竞态回归 |
| 7 | 手写 `format!` 转义数错、解析先于插入等低级错 | 测试：helper 生成 JSON、先入 map 再 walk |
